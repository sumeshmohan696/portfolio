Designed as a living cover letter and dynamic proof-of-work, the platform fuses enterprise DevOps infrastructure mechanics with real-world autonomous AI systems and interactive 3D graphics.

---

## 🛠️ Key Architectural Features

- **3D Datacenter Corridor Fly-Through (Three.js):**
  - Dual parallel rows of 12 server rack towers with metallic chassis frames, recessed drive bays, and floor gridlines.
  - Asynchronously blinking status LEDs and 400 floating data-bus particles.
  - Scroll-driven camera flight that zooms down the aisle directly into an individual Modular Server Chassis and pulsating AI Quantum Core.
- **Continuous Rolling Dropdown Ticker Reel:**
  - Embedded in the top floating navigation capsule.
  - 60fps liquid linear interpolation (`lerp 0.14`) that mirrors scroll position across all 10 architectural sections and settles cleanly into position with an active Cyber Teal neon glow.
- **Kinetic Scroll-Settling Content Physics:**
  - Distance-normalized mathematical transforms dynamically gliding headings, bento cards, and consoles along the Y/Z axes, snapping crisply into focus at `(0, 0, 0)` with 100% opacity.
- **Strict Teal, Black & White Color Architecture:**
  - Standardized on high-contrast **Cyber Teal (`#00E5C9`)**, **Pure Black (`#000000`)**, and **Crisp White (`#FFFFFF`)** with zero multi-color clutter.
- **Autonomous AI Systems Showcase:**
  - **FRIDAY:** Local voice-driven Windows 11 AI desktop assistant (Ollama `llama3.2:latest`, Edge-TTS, PowerShell automation).
  - **Tech World News & Intelligence Bot:** 24/7 cloud news intelligence daemon on Render Cloud with Telegram Webhook delivery and Gemini API fallback.
  - **Obsidian Second Brain Engine:** Synaptic knowledge compiler with bi-directional WikiLinks and remote mobile Telegram command bridge.
- **Operator CLI Terminal (`sumesh@sumeshmohan:~$`):**
  - Fully functional simulated terminal supporting 15 interactive commands (`help`, `prompts`, `experience`, `panapps`, `jio`, `ai`, `friday`, `cicd`, `certs`, `uptime`, `contact`, etc.).
- **5-Stage CI/CD Release Engine Simulator:**
  - Interactive visualization of enterprise delivery pipelines (Git Branching -> Jenkins Build -> Multi-Stage Docker -> Kubernetes Rolling Rollout -> Zabbix Telemetry).
